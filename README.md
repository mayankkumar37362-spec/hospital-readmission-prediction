# 🏥 Hospital Readmission Prediction

## 📌 Project Overview

This project predicts 30-day hospital readmissions using machine learning and healthcare analytics. The workflow includes data cleaning, exploratory data analysis (EDA), feature engineering, model development, and comparative evaluation of multiple machine learning algorithms.

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Jupyter Notebook
- Power BI *(Dashboard to be added)*

---

## 📊 Machine Learning Models

- Logistic Regression
- Balanced Logistic Regression
- Decision Tree
- Tuned Decision Tree
- Random Forest
- XGBoost

---

## 🎯 Best Model

XGBoost achieved the best balance between recall and overall predictive performance for identifying patients at risk of 30-day hospital readmission.
